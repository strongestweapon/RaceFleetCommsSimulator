# 경기정 통신 시뮬레이터

ILCA 경기장에서 여러 경기정이 RC 수신기로 데이터를 보낼 때 LoRa와 BLE Mesh의 도착률, 미갱신 경기정 수, 지연을 비교합니다. 평가 대상의 모든 경기정이 1초 안에 송신하고 수집기가 각 경기정의 보고를 한 번 이상 받으면 성공입니다.

**탐색**은 지도와 그래프를 화면 간격에 맞춰 갱신합니다. **고속 탐색**은 그래픽을 접고 후보를 연속으로 평가하며, 성공 후보 중 새 최선을 스냅샷으로 저장합니다. 스냅샷은 이력 탭에서 열 수 있습니다.

## 실행

Node.js 20 이상에서 다음 명령을 실행합니다. 외부 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

브라우저에서 [http://127.0.0.1:8876/](http://127.0.0.1:8876/)을 엽니다.

## macOS 앱

Rust, Xcode 도구, Tauri CLI 2가 설치된 환경에서 빌드합니다.

```sh
cargo tauri build --bundles app -- --locked
```

`src-tauri/target/release/bundle/macos`의 앱을 열면 시뮬레이터와 JSON 파일 저장·불러오기를 사용할 수 있습니다.

## 검증

```sh
npm test
node "ILCA-7-비교/compare-layouts.mjs"
```

두 번째 명령은 가상 경기정 대형별 반복 평가 결과를 JSON으로 출력합니다. 모델의 전파·파도 수치는 실측 보정 전 가정입니다.
